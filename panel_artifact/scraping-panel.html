أدوات الجمع
الكاشطات

            

              
              
            

          

          

          

            

              
              
            

          

        


        

          

            
كل كاشطة تفتح روابط موقع، وتشغّل سكربتاتك على صفحاته، وتحفظ العناصر التي تستخرجها. اختر المحرك لكل كاشطة: Apify يعمل من المتصفح عبر موصل Apify، وScrapling يعمل على خوادم Claude ضمن المهمة المجدولة.

            

              
              
              
            

          

          

        


        

          

            

              
الأساسيات
اسم الكاشطة ومحركها والمشروع الذي تخدمه.

              

                

                  
                  
                  اسم واضح يظهر في القائمة، بالعربية أو الإنجليزية.
                  
                

                

                  
                  
                  اختياري: للتنظيم فقط، لا يغيّر طريقة التشغيل.
                

              

              

                المحرك *Engine
                

                  
                  
                

                المدخلات نفسها للمحركين؛ إعدادات Apify الإضافية تظهر في قسم خاص عند اختياره.
                
              

              

                

                  
                  
                  معرّف الكاشطة: أحرف إنجليزية صغيرة وأرقام و _ و -. لا يتكرر، ولا يتغيّر بعد الحفظ.
                  
                

              

            


            

              
المتصفح Browser
كيف تُفتح الصفحات قبل تشغيل السكربتات عليها.

              

                

                  
                  
                  http أسرع: يطلب الصفحة ببصمة Chrome ولا يشغّل JavaScript الموقع. chromium للمواقع التي تبني محتواها بـ JavaScript.
                  مع Apify تعمل الصفحات دائماً في متصفح (apify/web-scraper)، فلا أثر لاختيار http هناك.
                

                

                  
                  
                  مع chromium فقط: متى تُعدّ الصفحة جاهزة لتشغيل السكربتات.
                

              

              

                
                
                اختياري: محدد CSS لروابط المنتجات في صفحة القائمة، يُستخدم حين لا يرجع سكربت القائمة حقل url. إذا كان هناك سكربت تفاصيل تُفتح هذه الروابط كصفحات تفاصيل، وإلا تُحفظ الروابط نفسها كعناصر {url}.
              

            


            

              
السكربتات والروابط Scripts & URLs
روابط البداية ومنطق الاستخراج بـ JavaScript لصفحات القائمة والتفاصيل.

              

                
                
                رابط في كل سطر، يبدأ بـ http:// أو https://. كل رابط صفحة قائمة.
                
              

              

                
                
                جسم دالة JavaScript يعمل في كل صفحة قائمة ويرجع مصفوفة كائنات (return [...]). الكائن الذي فيه url تُفتح صفحته كصفحة تفاصيل إذا كان هناك سكربت تفاصيل.
                
              

              

                
                
                اختياري: يعمل في كل صفحة تفاصيل ويرجع كائناً واحداً يُدمج مع عنصر القائمة. إذا كان وحده (بلا سكربت قائمة ولا محدد روابط) فكل رابط بداية عنصر واحد يُقرأ بهذا السكربت.
                
              

            


            

              
السلوك Behavior
عدد العناصر المتوقع وحالة التفعيل.

              

                

                  
                  
                  يتوقف السحب عند هذا العدد. 0 = بلا حد.
                  
                

              

              
            


            

              
التشغيل التلقائي Auto Trigger
تشغيل يومي في موعد ثابت.

              
              

                

                  
                  
                  بتوقيت المنطقة المختارة.
                  
                

                

                  
                  
                

              

            


            

              
Apify
الـ Actor الذي يشغّل الكاشطة على Apify، وإدخاله.

              

                
                
                بصيغة username/actor-name أو username~actor-name، مثل apify/web-scraper.
                
              

              

                
                
                اختياري. إذا تُرك فارغاً تبني الصفحة إدخالاً بأسلوب apify/web-scraper من الحقول أعلاه: startUrls و pageFunction من السكربتات ومحدد الروابط، و maxPagesPerCrawl من العناصر المستهدفة.
                
              

              
معاينة الإدخال الذي سيُرسل إلى Apify

            


            

              
بيانات إضافية Payload
نص حر يُحفظ مع الكاشطة للاستخدام لاحقاً.

              

                
                
                اختياري: JSON أو نص، يُحفظ كما هو ولا يؤثر في التشغيل.
