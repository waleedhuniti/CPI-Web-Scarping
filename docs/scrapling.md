# Scrapling browser fetcher

The existing CPI pipeline uses Apify for search collection and scripts/verify_pages.py
for the independent product-page check. This optional adapter adds Scrapling as an
alternative product-page fetcher while preserving the pages.json input contract.

## Why the platform template is not used

Scrapling's platform-template page documents ShopifySpider, which reads Shopify's
standard /collections.json and /products.json endpoints. Carrefour UAE and Lulu UAE
are not identified as Shopify stores in this project, and their parsers rely on
retailer-specific page structures. ShopifySpider is therefore not a drop-in fit.
This integration uses Scrapling's generic StealthyFetcher instead.

## Install (optional)

Keep the core project lightweight:

    pip install -r requirements-scrapling.txt
    scrapling install

## Run

Use the URL-list JSON generated by the CPI pipeline:

    python scripts/scrapling_product_pages.py lulu data/runs/2026-10-05/lulu_product_urls.json data/runs/2026-10-05/lulu_pages_scrapling.json

    python scripts/verify_pages.py lulu data/runs/2026-10-05/lulu_pages_scrapling.json data/runs/2026-10-05/lulu_matched.csv

Use carrefour for Carrefour URLs. Requests are sequential with a two-second
inter-request pause, and only the retailer's known HTTPS host is accepted.

## Human-verification handling

The fetcher uses Scrapling's stealth-enabled browser, but intentionally does not
enable automatic Cloudflare/Turnstile/CAPTCHA solving or other human-check bypass.
A detected challenge is written as human_verification_required with no page
content; it must not be treated as a product miss or accepted CPI price.

For an authorized operator workflow, add --manual-check. This opens a visible
browser, pauses when a challenge is detected, and allows the operator to complete
the retailer's own verification before retrying the URL in the same session.
Without this flag, the run remains unattended and records the challenge for review.

## Data quality

The output retains raw HTML for Lulu's embedded EAN data, JSON-LD for price/stock,
and readable text for Carrefour's Pack Size/Origin parser. CPI matching rules
(barcode evidence, exact pack quantity, page verification, and review-queue
decisions) remain unchanged.
